# 涂装轮廓库 · 2026-11-06 静态复核版

打开 `打开轮廓索引.html` 搜索型号和贴图。原库、安装涂装、J15T基准数据均未覆盖。

## 范围

包含J15T主贴图基准、J16/J10C既有模型布局的独立复核副本，以及Su-30SM、SM2、F-15EX新布局；F-15EX来自E:\WarThunder测试服。原始UV和全部几何保留，单独提供静态机体可见性与候选外表面，不能把后者当作全部可涂装表面。

J16修正两个蒙皮部件的432个三角形：24字节流位置在byte0、UV在byte12，旧解码误读了后面的字段。默认绑定姿态经261个顶点核验，最大加权位置差约1.76e-7m；未测试动画。J10C全图覆盖包含一个原生小立方体，不能据此证明外蒙皮精准，保留该源数据及说明。

## 精度与使用

- `assets` 每张贴图包含归一化UV、三维三角形、矢量边界、制作尺寸轮廓与坐标表。`metadata.json` 中尺寸、来源及哈希优先于文件名猜测。像素边界为x=u×W、y=(1-v)×H；像素中心为x+0.5、y+0.5。
- `data/seam_links.sqlite3` 是五机主贴图在默认静态机体场景下的接缝树变体。每连接两侧各存宽1像素、1～7像素的局部短线，只存数据库，不画进轮廓、涂装或渲染图。已连通分区不追加形成环的连接。
- 数据库主坐标为8192参考尺寸，可能不同于assets的制作尺寸和原生纹理尺寸。应先读models.width/height，按UV换算到目标贴图；不可直接复制整数坐标。
- `shared_edge`、`shared_vertex`、`near_gap`、`assembly_reference`含义不同。跨间隙参考桥只供索引；`needs_review`、`anchor_error_px`必须保留，不能当作同空间点。局部矩阵不等于整片曲面的无缝变形。
- `evidence/auxiliary_seams` 为J10C喷口及Su-30SM/SM2辅贴图的独立纹理树，按各自尺寸查询；没有虚构跨贴图连接。完整材质静态可见性另存位标记，遮挡三角形仍保留。
- 所选48个原短线纹素的透明背景回读通过，另有44个严格内部纹素对照通过。它们校验的是所选点的UV采样方向和像素相位，不是全库像素级精准证明。首次11个边缘混色失败及原因记录保留在本轮工作目录。
- 透明裁切、玻璃反射、部件激活、动画、损伤和游戏材质仍需游戏核验。可选附件布局没有逐项外观审查。

## 查询与证据

运行 `python tools/query_seams.py --model j_16 --chart ID` 或 `--connection ID` 查询；`python tools/validate_seam_db.py --db data/seam_links.sqlite3 --report validation.json` 只验证结构和数值一致性。

`evidence` 保存模拟图、相机、独立验证、来源与限制。主树和完整原始布局用途不同，不能仅以通过结构检查推断外观精准。资源仅用于本机已有游戏的涂装定位；游戏数据权利归权利人。
