# 数据库和像素约定

`config/data/seam_links.sqlite3` 使用 SQLite，schema_version=1。所有短线仅为数据记录，不修改输入图片。

| 表 | 内容 |
|---|---|
| models | 模型、贴图宽高、输入来源哈希、外表面筛选条件 |
| charts | part/island、面积、树根及父节点 |
| connections | 两侧分区、关系类型、实测距离、复核标志 |
| sides | 各侧 UV 与空间锚点、来源三角形、整数采样偏差 |
| pixels | 按 step 排序的局部单像素短线、展开坐标、循环坐标及空间回算 |
| transforms | 双向 UV 和像素局部仿射矩阵、条件数与锚点残差 |
| uv_aliases | 检出的完全相同 UV 三角形别名；不是完整重叠检测 |

## 树和关系类型

优先选择较长的真实共边，再选择共顶点接触，再用边界点间距联系剩余组件。并查集只接受连接不同组件的边，最终每模型 N 个节点、N-1 条连接。

- `shared_edge`：原始空间边量化至 0.01 mm 后相同。
- `shared_vertex`：仅共享空间顶点，不据此假设整条边连续。
- `near_gap`：独立锚点距离不超过 0.01 m，不能视为零间隙。
- `assembly_reference`：分离组件或原边界无法提供有效整数像素时的参考桥。可能跨越数米，必须按记录距离解释。

完整树保证索引可遍历，并不保证每条边都是真实相邻的物理接缝。筛选参考桥后会出现多个组件。已有库中的分区划分和重复 UV 使这一点尤其重要；不能靠增加假共边来掩盖真实分离。

## 单像素短线

浮点采样索引：`x = u*W - 0.5`，`y = (1-v)*H - 0.5`。整数 x/y 指像素中心。贴图原点为左上，UV 原点为左下。

每侧锚点附近向所属三角形内部生成宽 1 像素的 Bresenham 路径，最多 6 个网格步长，即 1～7 个像素。按 8 邻域连续；一旦离开所属三角形就截断。不同连接的短线彼此独立，不在岛内画长线。极窄边界三角形没有有效整数像素时，回退到该分区的代表三角形，并升级为需要复核的参考关系。

当前整数采样点距浮点锚点最大约 5.71 px，相关项已标记；这是离散边界采样的限制，不能用浮点转换残差很小来掩盖它。需要逐像素重采样时使用浮点锚点与矩阵，不能简单复制整数坐标。

UV 超过 0～1 时保留原值。`unwrapped_x/y` 是展开坐标，`x/y` 是按宽高取模后的图像位置，`tile_u/v` 记录展开所在格。不要把 J16 的重复 UV 截断到 0～1。

## 局部转换

以共同边切向和两侧向内方向建立局部切平面；B 侧跨边方向翻转后解 UV 仿射矩阵。密度、镜像和旋转保留在矩阵中。矩阵乘列向量 `[x,y,1]`；路径反向使用逆矩阵。

A-B-C 的矩阵组合用于锚点附近的局部定位。曲面、不同接缝的锚点位置和装配参考桥意味着这一组合不能充当整片非刚性贴图变形。`needs_review=1` 的链接需要人工检查。跨间隙路径不应自动用于无缝涂装生成。

## 验证

独立验证器以只读方式检查 SQLite 完整性和外键、树的连通无环、每侧像素数量、8 邻域连续、三角形内部采样、空间坐标回算、UV 原点与重复格、双向矩阵往返及实测间隙。当前检查 41815 个短线像素；结果保存在独立报告中。
