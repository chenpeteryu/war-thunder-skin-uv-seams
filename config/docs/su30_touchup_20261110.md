# SM / SM2 final label and continuous-root touchup — 2026-11-10

The user removed the top wing-root SU-30 / SM or SM2 lines and kept IRKUTSK at the original third-line position. The small horizontal-stabilizer title now retains only the original SU glyphs; the large 30SM / 30SM2 remains unchanged.

The previous native-C microdetail fade was rejected: reference structure lines must remain continuous instead of dissolving into original rivets/skin. The final tool builds four isolated native-side orthographic UV planes with depth selection, samples the original J16 texture, and extracts continuous structure paths. It keeps raw lower technical stencils, excludes source manufacturer ink, and preserves approved glyph footprints and chromatic accents. Target C rivets/skin are not blended into the root. The normal/material texture and native geometry/UV are unchanged.

The exact executable generator, glyph helper and two hash-bound profiles are published. Intermediate nearest-triangle or native-detail attempts are not the final method. Geometry-bound coordinate bundles are generated deterministically from these tools and native library geometry; user-owned artwork is never included in this repository.

```powershell
python config/tools/rebuild_sm_continuous_root_20261110.py --baseline-dir NOV9_INPUT_DDS --original-reference-dir ORIGINAL_REFERENCE_PNG --j16-color J16_BODY_C_DDS --output REVIEW_OUTPUT
```

Inputs are identified by SHA-256 in `su30sm_touchup_20261110.json` and `su30sm2_touchup_20261110.json`. The original-reference directory contains MODEL_c.png and the baseline directory contains MODEL_c.dds. Generated `candidate` C textures reproduced the final DDS byte-for-byte for both models. The generated coordinate bundles and color intermediates belong outside the native library asset directory.
