# Su-30SM 与 Su-30SM2 的布局比较（2026-11-06）

结论：大量部件共用UV布局，但不是完全相同的一套，不应直接把整张涂装互换。保留两型号独立目录、贴图名和接缝树。

## 主贴图

SM使用`su_30sm_c`，SM2使用`su_30sm2_c`。本轮原生LOD0主贴图几何分别含383448与384192个三角形。将每个三角形的顶点按UV排序、以1e-6 UV量化，并按原生部件名比较集合后，308个部件中305个集合相同，3个有差异：

| 原生部件 | SM独有UV三角形 | SM2独有UV三角形 |
|---|---:|---:|
| fuse（机身） | 606 | 997 |
| slat_l（左前缘缝翼） | 631 | 667 |
| slat_r（右前缘缝翼） | 550 | 600 |

这里比较的是分部件UV三角形集合，忽略顶点/三角形排列和完全重复项；不能据此断言三维几何、纹素密度或实际艺术稿的图案一定可互换。即使岛布局相同，也要检查接缝和目标型号纹理绑定。

## 其他贴图

两型号共同使用20个贴图名，其中18个UV数组逐项相同；`aku_170_launcher_c`虽然数组排列不同，分部件UV三角形集合仍一致。`su_30sm_pylon1_c`的集合确实存在差异。

- SM独有命名：`su_30sm_c`、`su_33_ecm_pod_c`。
- SM2独有命名：`su_30sm2_c`、`su_30sm2_ecm_pod_c`、`su_30sm2_pylon1_c`。
- 共用辅贴图`su_30sm_1_c`保留两套型号记录，不合并空间坐标或可见性证据。

## 复现和证据

运行`python config/tools/compare_sm_layouts_20261106.py`，默认读取本仓库aircraft目录，也可传入另一个assets目录。完整逐部件结果见[比较报告](../reviews/2026-11-06/evidence/sm_sm2_layout_comparison.json)。结论仅针对记录的本机资源版本，不假定未来更新仍保持相同。
