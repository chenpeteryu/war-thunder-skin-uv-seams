# 已遇到的易错点

- 复用其他机体的涂装参考时，应逐项区分可借鉴的样式与来源机体专属特征；除非用户明确要求沿用，不得把来源机体的编号、名称/称号、文字和专属标识复制到目标机体。例如制作 Su-30SM2 时参考 J16，不得把 J16 的“016”、“qianlong”或“潜龙”等特征内容一并搬过去；目标机体的特征应依据其自身要求确定。
- 制作过程中或完成后，复用已知、已确认的轮廓库时如发现并确认库中存在错误，应及时修正对应的轮廓、坐标、配置或代码，保留修正依据并完成相关校验。允许直接修改本仓库，并将修正提交、推送至 GitHub。尚未确认的问题应标记为待验证，不能把推测当作已确认修正。
- 同类机型外形相似不代表 UV 排序相同；内外侧、左右侧、前后段和重复 UV 必须逐面核对。岛编号也不是通用结构名称。
- 一个 UV 岛可能同时覆盖多个结构。中央柱体和发动机共享区域、垂尾小盖板附近的岛都不能用整岛纯色替换，否则会擦掉其他面的图案。
- 只按正面法线筛选会漏掉背面可见的进气口壁。需双向检查并保留真实遮挡；法线朝向也不能单独证明内饰。
- 对每个顶点分别找最近来源面，再线性插值 UV，可能跨到不同来源岛而拉出碎片。用单个一致来源面，或先做分区标签再在各标签内部查找；不要跨不连续 UV 混合。
- 像素中心有 0.5 偏移，且 UV 与图像 Y 方向相反。8192 和 4096 坐标不可混用。镜像/重复格必须保留，不要夹取到边界。
- 共边的浮点配准不意味着整数像素恰好重合。密度不同需重采样；极窄面可能没有整数中心。查看 anchor_error_px、矩阵条件数和复核标志。
- 生成树只消除冗余边。跨分离部件的 assembly_reference 方便查找，不能当成无缝边界；A-B-C 的局部矩阵也不是全局曲面展开。
- 喷口整体填均值会抹掉分瓣、烧蚀与材料变化。应同时检查颜色贴图和打包法线/材质贴图，保留来源细节，避免只恢复亮银颜色。
- `_c` 图案移走后，旧 `_n` 刻痕仍可能显现为黑点、栅格和断环。两者位置需联合检查。旋转/镜像搬运法线时使用 UV 到表面映射的正交方向变换，不能照搬所有通道或一律反相。
- 垂尾操作面应跨真实 UV 边界保持图案，但机械铰链、实际缝隙和天线不能通过填色“消除”。不能把原生模型突起误认为三角涂装。
- 鸭翼“下方”要明确为从下往上观察其下表面。俯视图、外侧垂尾图和进气口外壁正确，不能证明对应内侧已处理。
- 静态外表面可见性和 UV 别名检测均不完整：未命中的隐藏面、部分重叠、玻璃及动画状态需额外检查。当前库的座舱空间排除规则也有范围限制。
- 模拟输出只证明该几何、纹理和相机组合下的结果；不能称为实际游戏渲染验证。相机矩阵、输入来源和未决问题应随结果保存。
